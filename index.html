YT Monitor

An internal reporting tool for a single YouTube channel.

YT Monitor is a private Google Sheets + Google Apps Script tool used by the channel's own manager. Once a day it reads the channel's YouTube analytics (views, watch time, subscribers, estimated revenue) and video information, and writes them into a private Google Sheet so the channel team can track performance.

It is not a public service. It has no user accounts, it is not offered to other people, and it only accesses channels that the signed-in user already manages.

Data access

  • Read-only access to YouTube data and YouTube Analytics for the authorized channel.
  • Data is stored only in the owner's private Google Sheet.
  • No data is sold, shared or sent to any third party.
