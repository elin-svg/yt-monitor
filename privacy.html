Privacy Policy

YT Monitor · Last updated 1 November 2026

What this app is

YT Monitor is an internal tool used by the manager of a single YouTube channel to report on that channel's performance in a private Google Sheet. It is not offered to the public.

Data we access

With the user's permission, YT Monitor uses these read-only Google scopes:

  • youtube.readonly: channel and video details (titles, publish dates, durations, thumbnails, public view counts).
  • yt-analytics.readonly: channel analytics such as views, watch time and subscribers gained.
  • yt-analytics-monetary.readonly: estimated revenue for the channel.

YT Monitor cannot upload, edit or delete anything on YouTube.

How data is used and stored

  • Data is written only to a private Google Sheet owned by the user who authorized the app.
  • Authorization tokens are stored in the Google Apps Script project's private properties.
  • No data is sold, shared, or transferred to any third party, and it is not used for advertising.

Google API Services User Data Policy

YT Monitor's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can remove YT Monitor's access at any time at myaccount.google.com/permissions. Deleting the Google Sheet removes all stored data.
